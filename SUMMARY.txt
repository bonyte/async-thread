## 5 Key Patterns Implemented

### 1. **Participant Hash** ✅
Order-independent conversation deduplication
```python
participant_hash("user-a", "user-b") == participant_hash("user-b", "user-a")
```

### 2. **IntegrityError Retry** ✅
Distributed lock without explicit locking
```python
try:
    INSERT with unique constraint
except IntegrityError:
    ROLLBACK and SELECT existing
```

### 3. **Redis Unread Counter** ✅
O(1) operations without database queries
```python
INCR unread:{thread_id}    # on send
SET unread:{thread_id} 0   # on read
```

### 4. **Soft Deletes** ✅
Preserve data while supporting deletion
```python
is_deleted_by_sender = True/False
WHERE is_deleted_by_sender == False
```

### 5. **Append-Only Log** ✅
Message immutability for audit trail
```python
# Only INSERT, never UPDATE
```
